# Архитектура «Круг»

## Слои
`api → services → repositories → models`

- `api` принимает HTTP-запрос и вызывает сервис.
- `services` содержит бизнес-логику.
- `repositories` выполняет запросы к БД.
- `models` описывает таблицы SQLAlchemy.
- `schemas` задаёт Pydantic-контракты.
- `core` содержит настройки и общие зависимости; `db` — подключение и Base.

## Правила
1. Роутер не обращается к БД напрямую.
2. Сервисы используют репозитории; репозитории работают с моделями.
3. Нижние слои не импортируют верхние.
4. Profile не изменяет данные Posts напрямую — только через согласованный интерфейс.
5. Общие схемы нельзя переименовывать/менять без согласования.
6. Не допускать N+1: запрос не должен выполняться в цикле для каждого объекта.
